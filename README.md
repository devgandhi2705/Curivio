# Curivio

**Learn one topic properly, a few minutes a day.**

Name a topic and Curivio builds you a lesson from live sources — graded, cited, and
written for the level you picked. The next day's lesson starts where that one
finished, so three weeks in you are somewhere, not back at the introduction.

**→ [curivio.hf.space](https://devg-01-curivio.hf.space)**

---

## What it does

**A lesson a day, on one topic.** Each day is a short brief built from current
sources plus evergreen background, with every claim cited back to the page it
came from. Difficulty is yours to set, and the material deepens on its own as
you read.

**It remembers yesterday.** Each lesson refers back to what earlier ones
established by name, so the arc compounds instead of resetting.

**Ask past the lesson.** Any card opens into a conversation that already knows
what you just read — at whichever depth you want, with live web search when a
question outruns your files.

**Unpack any word.** Select a term mid-lesson and a popover explains it in
context, translates it, or reads it aloud. No new tab, no losing your place.

**Keep what mattered.** Bookmarks, Read Later, and notes on any day, all
searchable at once. Export a day as PDF or Markdown.

**Works on the train.** Everything you have opened is written to your device in
the background, so no signal changes nothing.

**Your own pace, your own look.** A dashboard tracks streak and consistency
without nagging; three colour modes, remembered per browser.

---

## Built with

React and Vite on the front, FastAPI and SQLite behind it, Gemini for generation
with Groq as fallback, Tavily for retrieval. Packaged as a Docker image and
running on Hugging Face Spaces.
